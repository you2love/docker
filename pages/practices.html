Docker 最佳实践

🔒

安全最佳实践

始终使用非 root 用户运行容器，限制容器权限，使用只读根文件系统，并定期扫描镜像漏洞。

# 在 Dockerfile 中创建非 root 用户
RUN addgroup -g 1001 -S nodejs && \
    adduser -S nodejs -u 1001
USER nodejs

# 使用只读根文件系统
docker run --read-only myapp:latest

# 使用用户命名空间
docker run --userns=host myapp:latest
📦

镜像大小优化

使用多阶段构建减少镜像大小，选择合适的基础镜像，合并 RUN 指令减少层数，并清理不必要的文件。

# 使用 Alpine 基础镜像
FROM node:18-alpine

# 多阶段构建
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci && npm cache clean --force
COPY . .
RUN npm run build

FROM node:18-alpine AS production
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
CMD ["npm", "start"]
🔄

持续集成/持续部署

使用 BuildKit 加速构建，利用缓存层，自动化测试，并使用 Docker Compose 进行多服务编排。

# 使用 BuildKit 构建
export DOCKER_BUILDKIT=1
docker build -t myapp:latest .

# 使用缓存
docker build --cache-from myapp:latest -t myapp:latest .

# CI/CD 中的多架构构建
docker buildx build --platform linux/amd64,linux/arm64 -t myapp:latest --push .
📊

监控和日志

集中化日志管理，使用健康检查，监控资源使用情况，并设置告警机制。

# 在 Dockerfile 中添加健康检查
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
    CMD curl -f http://localhost/health || exit 1

# 使用 Docker Compose 配置日志
services:
  app:
    image: myapp
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
🔗

网络和存储

使用自定义网络隔离服务，使用命名卷持久化数据，避免使用默认桥接网络。

# Docker Compose 网络配置
version: '3.8'
services:
  web:
    image: nginx
    networks:
      - frontend
    volumes:
      - web-data:/usr/share/nginx/html

  db:
    image: postgres
    networks:
      - backend
    volumes:
      - db-data:/var/lib/postgresql/data

networks:
  frontend:
    driver: bridge
  backend:
    driver: bridge

volumes:
  web-data:
  db-data:

综合最佳实践清单

  • 使用特定的标签而非 latest
  • 使用 .dockerignore 文件排除不需要的文件
  • 定期更新基础镜像和依赖
  • 使用 Docker 官方镜像作为基础
  • 为容器设置资源限制
  • 使用 secrets 管理敏感信息
  • 实施镜像签名和验证
  • 使用 Docker Bench for Security 审查配置
