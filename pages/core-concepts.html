📖 Docker 核心概念

理解 Docker 的基础概念是掌握容器技术的关键

📦

镜像 (Image)

只读模板，包含运行应用所需的代码、运行时、库和设置。采用分层存储，支持高效复用。

docker pull nginx:latest
🎯

容器 (Container)

镜像的运行实例，是独立的、可执行的软件单元。容器之间相互隔离，但共享主机内核。

docker run -d -p 80:80 nginx
📝

Dockerfile

定义镜像构建过程的文本文件，包含一系列指令，Docker 按这些指令组装镜像。

FROM node:18
COPY . /app
CMD ["npm", "start"]
🎼

Docker Compose

定义和运行多容器应用的工具，使用 YAML 文件配置应用服务、网络和数据卷。

docker-compose up -d

架构说明

  • 宿主机操作系统：提供底层系统资源和内核功能
  • Docker Engine：负责容器的创建、运行和管理
  • 镜像层：采用分层存储，多层只读层构成镜像
  • 容器层：在镜像基础上添加可写层，实现写时复制
  • 共享资源：容器共享宿主机内核，但彼此隔离

🎯 运行你的第一个容器

快速上手，体验 Docker 的魅力

1

拉取镜像

docker pull nginx:latest

从 Docker Hub 下载 Nginx 官方镜像

2

运行容器

docker run -d -p 8080:80 --name my-nginx nginx

后台运行容器，将主机 8080 端口映射到容器 80 端口

3

访问服务

# 在浏览器访问 http://localhost:8080
# 或查看容器状态
docker ps
docker logs my-nginx

查看运行状态和日志

4

停止和清理

docker stop my-nginx
docker rm my-nginx

停止并删除容器
