Docker 网络详解

🌐 Docker 网络概述

Docker 网络功能允许容器之间以及容器与主机之间的通信。Docker 提供了多种网络驱动，每种都有其特定的用途和功能。

查看网络

# 列出所有网络
docker network ls

# 查看特定网络详情
docker network inspect bridge

# 查看容器网络配置
docker inspect CONTAINER_NAME

创建自定义网络

# 创建桥接网络
docker network create my-bridge-network

# 创建覆盖网络（用于 Swarm）
docker network create --driver overlay my-overlay-network

# 创建 MACVLAN 网络
docker network create -d macvlan --subnet=172.16.86.0/24 --gateway=172.16.86.1 -o parent=eth0 pub-net

# 创建 IPVLAN 网络
docker network create -d ipvlan --subnet=192.168.1.0/24 --gateway=192.168.1.1 -o parent=eth0 ipvlan-net

网络驱动类型

  • Bridge: 默认网络驱动，适用于单主机上的容器通信
  • Host: 移除容器和 Docker 主机之间的网络隔离
  • Overlay: 用于连接多个 Docker 守护进程，适用于 Swarm
  • Macvlan: 为容器分配 MAC 地址，使其外观像物理设备
  • None: 禁用所有网络
  • 第三方插件: 其他网络实现

使用自定义网络

# 运行容器时指定网络
docker run -d --name container1 --network my-bridge-network nginx

# 将运行中的容器连接到网络
docker network connect my-bridge-network container2

# 断开容器与网络的连接
docker network disconnect my-bridge-network container1

# 使用自定义网络运行多个容器
docker run -d --name web --network my-bridge-network nginx
docker run -d --name db --network my-bridge-network mysql:8.0

Docker Compose 网络配置

version: '3.8'

services:
  web:
    image: nginx
    networks:
      - frontend
      - backend

  api:
    image: myapi
    networks:
      - backend

  db:
    image: postgres
    networks:
      - backend

networks:
  frontend:
    driver: bridge
  backend:
    driver: bridge
    internal: true  # 禁止外部访问

网络最佳实践

  • 使用自定义网络而非默认桥接网络
  • 使用有意义的网络名称
  • 根据安全需求分离网络（例如，前端和后端）
  • 定期清理未使用的网络
  • 使用内部网络限制对外访问
