🌐 Docker 网络配置

理解 Docker 网络模式，实现容器间通信

Bridge 模式（默认）

容器通过虚拟网桥通信，适合单主机多容器

# 创建 bridge 网络
docker network create mynet

# 使用自定义网络运行容器
docker run -d --name web --network mynet nginx
docker run -d --name db --network mynet postgres

# 查看网络列表
docker network ls

# 查看网络详情
docker network inspect mynet

Host 模式

容器使用主机网络栈，性能最优但隔离性低

# 使用 host 网络
docker run -d --network host nginx

# 容器直接使用主机 IP 和端口
# 注意：端口冲突风险

Overlay 模式

跨多主机容器的分布式网络，用于 Swarm 集群

# 创建 overlay 网络（需要在 Swarm 模式）
docker network create -d overlay myoverlay

# 在 Swarm 服务中使用
docker service create --network myoverlay nginx

# 查看 overlay 网络
docker network ls | grep overlay

Macvlan 模式

为容器分配 MAC 地址，像物理网络设备

# 创建 macvlan 网络
docker network create -d macvlan \
  --subnet=192.168.1.0/24 \
  --gateway=192.168.1.1 \
  -o parent=eth0 mymacvlan

# 使用 macvlan 网络
docker run -d --network mymacvlan nginx

🔗 容器间通信

在同一网络中的容器可以通过服务名相互访问

DNS 自动解析

# 创建网络
docker network create appnet

# 启动数据库容器
docker run -d --name db --network appnet postgres:16

# 启动应用容器
docker run -d --name app --network appnet \
  -e DATABASE_URL=postgres://db:5432/mydb myapp

# 容器可以通过服务名通信
# app 容器可以使用 "db" 作为主机名访问数据库

🔌 端口映射

将容器端口映射到主机端口，实现外部访问

基础端口映射

# 映射单个端口
docker run -d -p 8080:80 nginx

# 映射所有接口
docker run -d -p 0.0.0.0:8080:80 nginx

# 映射到 localhost
docker run -d -p 127.0.0.1:8080:80 nginx

多端口映射

# 映射多个端口
docker run -d \
  -p 8080:80 \
  -p 8443:443 \
  nginx

随机端口映射

# Docker 自动分配主机端口
docker run -d -p 80 nginx

# 查看映射的端口
docker port container_name
