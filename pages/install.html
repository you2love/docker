🐳 安装 Docker (2026 最新版)

完整的 Docker 安装指南，支持 macOS、Windows、Linux，包含 AI 工具配置

📦 2026 年最新版本信息

Docker Desktop 4.61.0+
Docker Engine 29.0+
BuildKit 0.25.2+
Docker Scout 内置
Compose v5.0+
新特性： Ask Gordon (AI) Docker Model Runner Compose v5 MCP Toolkit containerd image store
🍎

macOS 安装

方案一：Docker Desktop（推荐）

官方桌面应用，包含完整功能和 AI 工具

# 使用 Homebrew 安装
brew install --cask docker-desktop

# 启动 Docker Desktop
open -a Docker

# 等待启动完成后验证
docker --version
docker compose version
docker scout version
注意：
  • 需要 macOS 12.0+ (Monterey 或更高版本)
  • Apple Silicon 和 Intel Mac 均支持
  • 首次启动需要授予权限

方案二：Colima（轻量级）

开源替代方案，更轻量，适合命令行用户

# 安装 Colima 和 Docker CLI
brew install docker colima docker-compose

# 启动 Colima（可配置 CPU 和内存）
colima start --cpu 4 --memory 8 --disk 100

# 验证安装
docker --version
docker run hello-world

# 查看状态
colima status
优势： 更轻量、启动更快、免费无限制

方案三：OrbStack（高性能）

2026 年流行的轻量级替代，性能优异

# 使用 Homebrew 安装
brew install orbstack

# 启动 OrbStack
orbstack start

# OrbStack 自动替换 docker 命令
docker --version
特点： 启动快 5 倍、内存占用少 50%、原生支持 Linux 容器
🪟

Windows 安装

方案一：Docker Desktop + WSL2（推荐）

最佳性能，完整功能支持

# 1. 启用 WSL2（需要管理员权限）
wsl --install -d Ubuntu

# 2. 安装 Docker Desktop
winget install Docker.DockerDesktop

# 或使用 Chocolatey
choco install docker-desktop

# 3. 重启电脑后启动 Docker Desktop
# 4. 在设置中启用 WSL2 集成

# 5. 验证安装
docker --version
docker compose version
wsl --list --verbose
系统要求：
  • Windows 10 21H2+ 或 Windows 11
  • 需要启用虚拟化（VT-x/AMD-V）
  • WSL2 内核更新

方案二：Rancher Desktop（开源）

开源免费，支持 containerd 和 Docker Engine

# 使用 winget 安装
winget install RancherDesktop.RancherDesktop

# 或使用 Chocolatey
choco install rancher-desktop

# 启动后选择容器运行时（containerd 或 Docker）

方案三：WSL2 原生安装

在 WSL2 中直接安装 Docker Engine

# 进入 WSL2
wsl -d Ubuntu

# 安装 Docker Engine（在 WSL2 内执行）
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 添加用户到 docker 组
sudo usermod -aG docker $USER

# 退出并重新进入 WSL2 使组生效
exit
wsl -d Ubuntu

# 验证
docker --version
docker run hello-world

Linux 安装

Ubuntu / Debian

# 方法一：使用官方脚本（最简单）
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 方法二：使用官方 apt 仓库
# 卸载旧版本
sudo apt-get remove docker docker-engine docker.io containerd runc

# 安装依赖
sudo apt-get update
sudo apt-get install ca-certificates curl gnupg lsb-release

# 添加 GPG 密钥
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 添加仓库
echo "deb [arch=$(dpkg --print-architecture) \
  signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker Engine
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin

# 添加用户到 docker 组（避免使用 sudo）
sudo usermod -aG docker $USER

# 验证
docker --version
docker compose version

CentOS / RHEL / Fedora

# Fedora / CentOS Stream
sudo dnf -y install dnf-plugins-core
sudo dnf config-manager --add-repo \
  https://download.docker.com/linux/fedora/docker-ce.repo

sudo dnf install docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker

# 添加用户到 docker 组
sudo usermod -aG docker $USER

# 验证
docker --version

Arch Linux

# 使用 pacman 安装
sudo pacman -S docker docker-compose buildx

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker

# 添加用户到 docker 组
sudo usermod -aG docker $USER

# 验证
docker --version

验证安装和配置

# 1. 检查 Docker 版本
docker --version
# 输出：Docker version 29.0.0, build ...

# 2. 检查 Docker Compose
docker compose version
# 输出：Docker Compose version v2.40.0

# 3. 运行测试容器
docker run hello-world
# 如果看到欢迎信息，说明安装成功

# 4. 检查 BuildKit（构建引擎）
docker buildx version
# 输出：github.com/docker/buildx v0.25.2

# 5. 检查 Docker Scout（安全工具）
docker scout version
# 输出：Docker Scout 1.18.0+

# 6. 查看系统信息
docker info
# 查看容器、镜像、存储驱动等信息

# 7. 测试 Ask Gordon（AI助手，需要Docker Desktop）
docker ai
# 打开AI助手的交互界面

# 8. 检查 containerd image store（新特性）
docker info | grep "Storage Driver"
# 输出：containerd (如果启用了containerd image store)

🔧 常见问题排查

问题：无法连接 Docker daemon

解决：确保 Docker Desktop 正在运行，或执行 sudo systemctl start docker

问题：权限错误（permission denied）

解决：将用户添加到 docker 组后，需要重新登录或执行 newgrp docker

问题：WSL2 集成不工作

解决：在 Docker Desktop 设置中启用 WSL2 集成，确保 WSL2 已正确安装

问题：构建速度慢

解决：确保 BuildKit 已启用 export DOCKER_BUILDKIT=1，使用构建缓存

⚙️

配置优化（2026 推荐）

启用 BuildKit（现代构建引擎）

# 在 ~/.bashrc 或 ~/.zshrc 中添加
export DOCKER_BUILDKIT=1
export BUILDKIT_PROGRESS=plain

# BuildKit 已在 Docker 23.0+ 中默认启用
# 无需额外配置，它提供了更快的构建速度和更好的缓存

配置 Docker Scout

# 登录 Docker Hub（启用 Scout）
docker login

# 配置 Scout 自动扫描
# ~/.docker/config.json
{
  "scout": {
    "autoScan": true,
    "severityThreshold": "high"
  }
}

优化 Docker Desktop 资源

在 Docker Desktop 设置中调整：

  • CPUs: 4-8 核（根据主机配置）
  • Memory: 8-16GB
  • Disk image size: 100GB+
  • Enable VirtioFS: 开启（提升文件共享性能）
  • Enable gRPC FUSE: 关闭（使用 VirtioFS）

配置镜像加速器（中国大陆）

# 编辑 daemon.json
sudo nano /etc/docker/daemon.json

# 添加镜像加速器
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://registry.docker-cn.com"
  ]
}

# 重启 Docker
sudo systemctl daemon-reload
sudo systemctl restart docker
