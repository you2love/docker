Docker 数据卷详解

💾 Docker 数据卷概述

数据卷是 Docker 中用于持久化数据的机制，它独立于容器生命周期，即使容器被删除，数据卷中的数据仍然存在。

数据卷操作命令

# 创建数据卷
docker volume create my-volume

# 列出所有数据卷
docker volume ls

# 查看数据卷详情
docker volume inspect my-volume

# 删除数据卷
docker volume rm my-volume

# 清理未使用的数据卷
docker volume prune

# 查看所有数据卷（包括未使用的）
docker volume ls -q | xargs docker volume inspect

挂载数据卷到容器

# 使用命名卷
docker run -d --name my-container -v my-volume:/app/data nginx

# 使用匿名卷
docker run -d --name my-container -v /app/data nginx

# 使用绑定挂载（主机目录）
docker run -d --name my-container -v /host/path:/container/path nginx

# 使用临时文件系统（内存中）
docker run -d --name my-container --tmpfs /app/data nginx

# 只读挂载
docker run -d --name my-container -v my-volume:/app/data:ro nginx

# 设置挂载选项
docker run -d --name my-container -v my-volume:/app/data:rw,Z nginx

数据卷类型

  • 命名卷: Docker 管理的持久化存储，存储在主机的特定位置
  • 匿名卷: 没有指定名称的卷，由 Docker 自动分配名称
  • 绑定挂载: 挂载主机文件系统中的文件或目录到容器
  • 临时文件系统: 挂载到内存中的临时文件系统（tmpfs）

Docker Compose 中的数据卷

version: '3.8'

services:
  web:
    image: nginx
    volumes:
      # 命名卷
      - web-data:/usr/share/nginx/html
      # 绑定挂载
      - ./html:/usr/share/nginx/html
      # 匿名卷
      - /tmp/cache
      # 只读绑定挂载
      - ./config:/etc/nginx/configs:ro
      # 临时文件系统
      - type: tmpfs
        target: /run
        tmpfs:
          size: 100M

  db:
    image: postgres:15
    volumes:
      # 命名卷用于数据库持久化
      - db-data:/var/lib/postgresql/data
    environment:
      POSTGRES_DB: myapp
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password

volumes:
  web-data:
  db-data:
    driver: local
    driver_opts:
      type: none
      o: bind
      device: /opt/postgres-data

数据卷备份和恢复

# 创建备份容器
docker run --rm -v my-volume:/volume -v $(pwd):/backup alpine tar czf /backup/backup.tar.gz -C /volume .

# 恢复备份
docker run --rm -v my-volume:/volume -v $(pwd):/backup alpine tar xzf /backup/backup.tar.gz -C /volume

# 使用专门的备份工具
docker run --rm -it -v my-volume:/data -v backup-container:/backup alpine tar -cvf - -C /data . | tar -xvf - -C /backup

# 从主机备份
sudo tar -czf backup.tar.gz -C /var/lib/docker/volumes/my-volume/_data .

数据卷最佳实践

  • 使用命名卷而非绑定挂载，以获得更好的可移植性
  • 为生产环境使用专用的存储解决方案
  • 定期备份重要数据卷
  • 使用卷驱动程序扩展功能（如加密、远程存储）
  • 合理规划卷的权限和访问模式
