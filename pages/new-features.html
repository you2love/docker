Docker 新特性

🤖

Ask Gordon

Docker 内置的 AI 助手，通过自然语言交互帮助编写、分析和优化 Dockerfile。命令：docker ai

🧠

Docker Model Runner

管理和运行 AI 模型的官方工具，支持本地推理和与 Compose 集成。已在 4.45.0 中 GA。

🎼

Compose v5

引入新的官方 Go SDK，提供全面的 API 用于集成 Compose 功能。在 4.56.0 中发布。

🔗

MCP Toolkit

Model Context Protocol 工具包，已在 Docker Desktop 中广泛集成，支持 100+ MCP 服务器。

📦

containerd image store

新的镜像存储后端，在 Docker Engine v29 中成为默认。提供更好的性能和兼容性。

🔍

Docker Scout

AI 增强的漏洞扫描、SBOM 生成、合规检查。实时监控镜像安全状态，自动修复安全风险。

⚡

cgroup v2 支持

cgroup v1 已废弃，cgroup v2 成为推荐选项。支持到 2029 年 5 月，建议尽快迁移。

🔥

nftables 支持

实验性的 nftables 防火墙后端，可设置 --firewall-backend=nftables 启用。

使用 Docker Scout 进行安全扫描

# 扫描镜像漏洞
docker scout cves myapp:latest

# 快速漏洞扫描
docker scout quickview myapp:latest

# 生成 SBOM（软件物料清单）
docker scout sbom myapp:latest --output sbom.json

# 查看镜像详情和依赖关系
docker scout repo myapp:latest

# 比较镜像差异
docker scout compare old:latest new:latest

# CI/CD 集成（失败如果发现高危漏洞）
docker scout cves --exit-code 1 --severity high,critical myapp:latest

使用 BuildKit 2.0 分布式构建

# 设置分布式构建缓存
export BUILDKIT_REMOTE_CACHE=type=registry,ref=myregistry.com/cache

# 使用远程构建器
docker buildx build \
  --builder=my-builder \
  --cache-from=type=registry,ref=myregistry.com/cache \
  --cache-to=type=registry,ref=myregistry.com/cache,mode=max \
  -t myapp:latest \
  .

# 创建远程构建器
docker buildx create --name remote-builder \
  --driver=docker-container \
  --driver-opt image=moby/buildkit:latest \
  --bootstrap

# 并行构建多架构镜像
docker buildx build \
  --platform linux/amd64,linux/arm64,linux/arm/v7 \
  -t myapp:multiarch \
  --push .

使用 eBPF 进行监控

# 安装 bpftrace（如果未安装）
sudo apt-get install bpftrace

# 监控容器网络流量
sudo bpftrace -e '
tracepoint:syscalls:sys_enter_connect / comm == "containerd" / {
  printf("Connect from PID %d to %s\n", pid, str(args->uservaddr, 16));
}'

# 监控容器文件系统访问
sudo bpftrace -e '
tracepoint:syscalls:sys_enter_openat / comm == "containerd" / {
  printf("PID %d opened file: %s\n", pid, str(args->filename));
}'

# 使用 Sysdig 进行高级监控
sysdig container.name=web-app

# 使用 Falco 进行安全监控
falco -r /etc/falco/rules.local.yaml

⚠️ 废弃特性

以下特性已被标记为废弃或移除，请及时迁移到新的解决方案

🔮

WASM 工作负载

已在 Docker Desktop 4.55.0 (2025-12-16) 中标记为废弃

移除计划：未来的 Docker Desktop 版本

替代方案：使用传统 Linux 容器

⚖️

cgroup v1

已在 Docker Engine v29 中标记为废弃

支持期限：至少到 2029 年 5 月

替代方案：迁移到 cgroup v2

🔒

Docker Content Trust

已从 Docker CLI 中移除

移除版本：Docker Engine v29.0.0

替代方案：可作为单独插件构建使用

📦

Legacy 图形驱动

containerd image store 成为新安装的默认选项

变更版本：Docker Engine v29.0.0

说明：不影响现有配置，仅影响新安装
