Docker 目录结构详解

📁 为什么了解 Docker 目录结构很重要？

Docker 在主机上创建了多个目录用于存储镜像、容器、卷、网络等数据。了解这些目录的结构和用途可以帮助您：

  • 有效管理存储空间
  • 快速定位和备份重要数据
  • 解决存储相关问题
  • 优化 Docker 性能
  • 进行故障排查

查看 Docker 根目录

# 查看 Docker 根目录位置
docker info | grep "Docker Root Dir"

# 输出示例（Linux/Mac）：
# Docker Root Dir: /var/lib/docker

# Windows 输出示例：
# Docker Root Dir: C:\ProgramData\Docker

# 查看目录大小
du -sh /var/lib/docker/*

Docker 完整目录结构

/var/lib/docker/                      # Docker 根目录
├── aufs/                             # AUFS 存储驱动（如果使用 AUFS）
├── buildkit/                         # BuildKit 构建缓存
│   ├── cache.db                      # BuildKit 缓存数据库
│   └── snapshots.db                  # BuildKit 快照数据库
├── containers/                       # 容器数据
│   ├── {container-id}/               # 单个容器目录
│   │   ├── config.v2.json            # 容器配置
│   │   ├── hostconfig.json           # 容器主机配置
│   │   ├── hostname                  # 容器主机名
│   │   ├── hosts                     # 容器 hosts 文件
│   │   ├── resolv.conf               # DNS 配置
│   │   └── ...                       # 其他容器文件
├── image/                            # 镜像数据
│   ├── imagedb.json                  # 镜像数据库
│   ├── layerdb/                      # 镜像层数据库
│   │   └── sha256/                   # 按 SHA256 哈希组织的层
│   └── ...
├── network/                          # 网络配置
│   └── files/
│       ├── network-config.db         # 网络配置数据库
│       └── network-state.db          # 网络状态数据库
├── plugins/                          # Docker 插件
├── swarm/                            # Swarm 集群配置
├── tmp/                              # 临时文件
├── trust/                            # 内容信任配置
├── volumes/                          # 命名卷数据
│   └── {volume-hash}/                # 单个卷目录
└── ...                               # 其他文件和目录

关键目录说明

  • /var/lib/docker/containers/: 存放所有容器的配置和日志文件
  • /var/lib/docker/image/: 存放镜像元数据和层信息
  • /var/lib/docker/volumes/: 存放命名卷的数据
  • /var/lib/docker/network/: 存放网络配置信息
  • /var/lib/docker/buildkit/: 存放 BuildKit 构建缓存

管理 Docker 目录

# 查看磁盘使用情况
docker system df

# 查看详细磁盘使用情况
docker system df -v

# 清理未使用的数据
docker system prune

# 清理所有未使用数据（包括镜像）
docker system prune -a

# 清理构建缓存
docker builder prune

# 清理指定容器的日志
truncate -s 0 $(docker inspect --format='{{.LogPath}}' CONTAINER_ID)
