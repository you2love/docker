Docker 常用命令

镜像管理

docker images 列出本地镜像
docker pull IMAGE_NAME 从仓库拉取镜像
docker push IMAGE_NAME 推送镜像到仓库
docker rmi IMAGE_ID 删除本地镜像
docker build -t NAME . 构建镜像
docker tag SOURCE TARGET 标记镜像

容器管理

docker ps 列出运行中的容器
docker ps -a 列出所有容器
docker run IMAGE 运行容器
docker start CONTAINER 启动容器
docker stop CONTAINER 停止容器
docker rm CONTAINER 删除容器

系统管理

docker system df 查看磁盘使用情况
docker system prune 清理未使用数据
docker stats 查看容器资源使用情况
docker info 查看系统信息
docker version 查看版本信息
docker login 登录到仓库

调试与日志

docker logs CONTAINER 查看容器日志
docker exec -it CONTAINER COMMAND 进入容器执行命令
docker inspect CONTAINER 查看容器详细信息
docker top CONTAINER 查看容器内进程
docker diff CONTAINER 查看容器文件系统变化
docker port CONTAINER 查看端口映射

高级命令示例

# 运行一次性容器
docker run --rm -it ubuntu bash

# 挂载数据卷和端口映射
docker run -d -p 8080:80 -v my-volume:/data nginx

# 使用环境变量
docker run -e ENV_VAR=value nginx

# 连接到特定网络
docker run --network my-network nginx

# 设置容器资源限制
docker run --memory=512m --cpus=1.0 nginx

# 查看实时统计信息
docker stats --no-stream

# 批量操作容器
docker ps -q | xargs docker stop

# 查找特定镜像
docker images --filter reference="nginx:*"

# 查看容器 IP 地址
docker inspect -f '{{range.NetworkSettings.Networks}}{{.IPAddress}}{{end}}' CONTAINER

# 复制文件到/从容器
docker cp CONTAINER:/path/to/file /local/path
docker cp /local/path CONTAINER:/path/to/file

实用技巧

  • 使用 --rm 标志自动删除退出的容器
  • 使用 -d 标志在后台运行容器
  • 使用 -it 标志获取交互式终端
  • 使用 --name 为容器指定名称
  • 使用 -v 挂载数据卷以持久化数据
  • 使用 -p 映射端口以访问容器服务
