📝 Dockerfile 最佳实践

遵循最佳实践，创建高效、安全的 Docker 镜像

标准 Dockerfile 示例

# syntax=docker/dockerfile:1.7

# 使用特定版本的轻量级基础镜像
FROM node:20-alpine3.19 AS base

# 设置工作目录
WORKDIR /app

# 安装依赖时使用缓存加速
FROM base AS deps
RUN --mount=type=cache,target=/root/.npm \
    npm pkg set scripts.prepare="" && \
    npm ci --only=production

# 构建阶段
FROM base AS builder
RUN --mount=type=cache,target=/root/.npm \
    npm ci && \
    npm run build

# 生产镜像
FROM base AS production

# 创建非 root 用户
RUN addgroup -g 1001 -S nodejs && \
    adduser -S nodejs -u 1001

# 复制依赖和生产文件
COPY --from=deps /app/node_modules ./node_modules
COPY --from=builder /app/dist ./dist
COPY package.json ./

# 设置用户和权限
USER nodejs

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s \
  --start-period=5s --retries=3 \
  CMD wget --quiet --tries=1 --spider \
      http://localhost:3000/health || exit 1

EXPOSE 3000

CMD ["node", "dist/server.js"]

关键实践要点

✅
使用多阶段构建

分离构建环境和运行环境，减小最终镜像大小

✅
利用构建缓存

使用--mount=type=cache加速依赖安装

✅
非 root 用户运行

提高容器安全性，防止权限提升攻击

✅
健康检查

监控容器状态，自动重启异常容器

✅
使用 .dockerignore

排除不必要的文件，减小构建上下文

✅
固定版本标签

避免使用latest，确保构建可重复

📚 Dockerfile 指令详解

常用 Dockerfile 指令的使用方法和最佳实践

FROM

指定基础镜像

FROM node:20-alpine
FROM ubuntu:22.04 AS builder

WORKDIR

设置工作目录

WORKDIR /app
# 自动创建目录（如不存在）

COPY / ADD

复制文件到镜像

COPY . /app
COPY --from=builder /dist .
ADD app.tar.gz /app

RUN

执行命令

RUN apt-get update && \
    apt-get install -y python3
RUN --mount=type=cache npm ci

CMD / ENTRYPOINT

容器启动命令

CMD ["node", "server.js"]
ENTRYPOINT ["python", "app.py"]
CMD ["--debug"]

ENV

设置环境变量

ENV NODE_ENV=production
ENV PATH="/app/bin:${PATH}"

EXPOSE

声明暴露端口

EXPOSE 3000
EXPOSE 8080/tcp 8443/udp

USER

指定运行用户

USER nodejs
USER 1001:1001
