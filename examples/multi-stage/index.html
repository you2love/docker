多阶段构建

多阶段构建指南

多阶段构建是一种强大的 Docker 功能，允许您在单个 Dockerfile 中使用多个构建阶段，从而减小最终镜像的大小并提高安全性。

Node.js 多阶段构建示例

# syntax=docker/dockerfile:1.4
# 构建阶段
FROM node:18-alpine AS builder

WORKDIR /app
COPY package*.json ./

# 启用 npm ci 的 BuildKit 缓存
RUN --mount=type=cache,target=/root/.npm \
    npm ci

COPY . .
RUN npm run build

# 运行阶段
FROM node:18-alpine AS runner

WORKDIR /app

# 从构建阶段复制构建产物
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/public ./public
COPY --from=builder /app/package*.json ./

# 安装生产依赖
RUN npm ci --only=production

# 创建非 root 用户
RUN addgroup -g 1001 -S nodejs && \
    adduser -S nodejs -u 1001
USER nodejs

# 暴露端口
EXPOSE 3000

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
    CMD wget --no-verbose --tries=1 --spider http://localhost:3000/health || exit 1

# 启动应用
CMD ["npm", "start"]

Go 应用多阶段构建示例

# syntax=docker/dockerfile:1.4
# 构建阶段
FROM golang:1.21-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -o main .

# 运行阶段 - 使用 Distroless 基础镜像
FROM gcr.io/distroless/static-debian11

WORKDIR /
COPY --from=builder /app/main .

# 暴露端口
EXPOSE 8080

# 运行应用
ENTRYPOINT ["/main"]

Java Spring Boot 多阶段构建示例

# syntax=docker/dockerfile:1.4
# 构建阶段
FROM maven:3.9-eclipse-temurin-17 AS builder

WORKDIR /app
COPY pom.xml .
COPY src ./src

# 构建应用并跳过测试（测试将在单独的阶段运行）
RUN mvn clean package -DskipTests

# 测试阶段
FROM maven:3.9-eclipse-temurin-17 AS tester
WORKDIR /app
COPY pom.xml .
COPY src ./src
COPY --from=builder /app/target/*.jar ./app.jar

# 运行测试
RUN java -Dspring.profiles.active=test -jar app.jar --test

# 运行阶段
FROM eclipse-temurin:17-jre-alpine

WORKDIR /app

# 创建非 root 用户
RUN addgroup -g 1001 -S spring && \
    adduser -S spring -u 1001

# 从构建阶段复制 JAR 文件
COPY --from=builder /app/target/*.jar app.jar

USER spring

# 暴露端口
EXPOSE 8080

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s --start-period=30s --retries=3 \
    CMD wget --no-verbose --tries=1 --spider http://localhost:8080/actuator/health || exit 1

# 启动应用
ENTRYPOINT ["java", "-jar", "app.jar"]

多阶段构建的 Docker Compose 示例

version: '3.8'

services:
  # 使用多阶段构建的应用
  app:
    build:
      context: .
      dockerfile: Dockerfile
      target: runner  # 指定最终运行阶段
      args:
        - BUILD_ENV=production
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
    volumes:
      - ./uploads:/app/uploads
    restart: unless-stopped

  # 构建服务（用于 CI/CD）
  build-service:
    build:
      context: .
      dockerfile: Dockerfile
      target: builder  # 指定构建阶段
    volumes:
      - build-output:/app/dist
    command: |
      sh -c "
        npm run build &&
        cp -r dist/* /output/
      "
