多阶段构建示例

这个镜像使用多阶段构建技术，显著减小了最终镜像大小

📊 构建阶段说明

第一阶段：构建环境

使用完整的 Node.js 环境，包含构建工具和依赖

基础镜像： node:18

目的： 编译和构建应用

第二阶段：运行环境

使用轻量级的 Nginx Alpine 镜像

基础镜像： nginx:alpine

目的： 只包含运行时所需的文件

✨ 多阶段构建的优势

  • 减小镜像大小： 最终镜像只包含运行时文件
  • 提高安全性： 减少攻击面
  • 加快部署速度： 更小的镜像拉取更快
  • 优化存储： 节省磁盘空间
  • 分离关注点： 构建和运行环境解耦
构建命令：

docker build -t multi-stage-app .

查看 Dockerfile 了解多阶段构建的实现细节
