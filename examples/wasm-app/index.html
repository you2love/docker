WASM 应用容器化

WASM 容器化指南

WebAssembly (WASM) 容器是 Docker 的革命性特性，将 WASM 模块作为容器运行，提供接近原生的性能、极小的镜像大小和更强的隔离性。

WASM Dockerfile 示例

# syntax=docker/dockerfile:1.6
# 构建阶段 - 使用 WasmEdge 运行时
FROM rust:1.70 AS builder

WORKDIR /app

# 安装 WASM 目标
RUN rustup target add wasm32-wasi

# 创建新项目
RUN cargo new hello-wasm
WORKDIR /hello-wasm

# 复制 Cargo.toml
COPY Cargo.toml .

# 复制源代码
COPY src ./src

# 构建为 WASM
RUN cargo build --target wasm32-wasi --release

# 运行阶段
FROM scratch
COPY --from=builder /hello-wasm/target/wasm32-wasi/release/hello-wasm.wasm ./
COPY index.html ./
COPY manifest.json ./

CMD ["hello-wasm.wasm"]

使用 Spin 框架的 WASM 应用

# syntax=docker/dockerfile:1.6
# 构建阶段
FROM rust:1.70 AS builder

WORKDIR /app

# 安装 Spin CLI
RUN curl -fsSL https://developer.fermyon.com/downloads/installer.sh | bash

# 安装 WASM32-WASI 目标
RUN rustup target add wasm32-wasi

# 创建 Spin 应用
RUN spin new --from https://github.com/fermyon/spin/templates hello-wasm
WORKDIR /app/hello-wasm

# 构建应用
RUN spin build

# 运行阶段
FROM scratch
COPY --from=builder /app/hello-wasm/spin.toml ./
COPY --from=builder /app/hello-wasm/target/wasm32-wasi/release/hello-wasm.wasm ./

CMD ["spin", "up"]

WASM 应用的 Docker Compose 示例

version: '3.8'

services:
  # WASM 微服务
  wasm-api:
    image: wasmcloud/http-hello-world
    runtime: io.containerd.wasmedge.v1  # 或 io.containerd.runsc.v1
    ports:
      - "8080:8080"
    deploy:
      resources:
        limits:
          cpus: '0.5'
          memory: 50M
    restart: unless-stopped

  # 传统容器（用于数据库）
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data

  # WASM 边缘计算服务
  edge-compute:
    image: my-wasm-edge-service:latest
    runtime: io.containerd.wasmedge.v1
    environment:
      - WASM_LOG_LEVEL=info
      - EDGE_REGION=us-west-2
    ports:
      - "9000:80"
    restart: unless-stopped

volumes:
  redis-data:

WASM vs 传统容器对比

# 传统容器
镜像大小：~150MB (Node.js 应用)
启动时间：~1-2 秒
内存占用：~50-100MB
隔离性：Linux 命名空间 + cgroups

# WASM 容器
镜像大小：~500KB - 1MB
启动时间：~10-50ms
内存占用：~5-10MB
隔离性：WASM 能力模型 + 沙箱

# 性能提升：
- 镜像拉取速度：提升 100-200 倍
- 冷启动时间：提升 20-100 倍
- 资源利用率：提升 5-10 倍

# 启用 WASM 支持（需要 Docker 27.0+）
export DOCKER_CLI_EXPERIMENTAL=enabled

# 运行 WASM 容器
docker run --runtime=io.containerd.wasmedge.v1 --rm -p 8080:8080 \
  wasmcloud/http-hello-world
